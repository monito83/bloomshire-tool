# Guía de Internacionalización (i18n) — Bloomshire Tool

Este documento define las reglas de internacionalización para el frontend de Bloomshire Tool (`i18next` + `react-i18next`).

---

## 1. Principio Fundamental
- **Cero strings crudos**: Todo texto visible al usuario final debe accederse mediante `t('clave')`.
- **Idioma base y fallback**: El idioma base del código y el juego es **inglés (`en`)**. Si falta una traducción en español (`es`) o en cualquier otro idioma, el sistema muestra el texto en inglés, nunca la clave cruda ni cadenas vacías.
- **Sin recarga**: El cambio de idioma es instantáneo y reactivo en caliente.

---

## 2. Convención y Formato de Claves
- Las claves se redactan en **inglés**, organizadas por módulos en `src/i18n/locales/{lang}/<namespace>.json`.
- Formato jerárquico estándar: `modulo.seccion.nombre` (o `seccion.nombre` dentro de un namespace modular).
- Ejemplos:
  ```javascript
  // Con hook por namespace:
  const { t } = useTranslation('header');
  t('sync.button'); // => "Sync" en EN, "Sync" en ES
  t('gold.tooltip', { amount: '1.200' });
  ```

---

## 3. Variables, Plurales y Concatenación
- **Nunca concatenar strings** (ej. `"Total: " + count + " items"` es un antipatrón prohibido).
- **Interpolación i18next**: Usar sintaxis `{{variable}}`.
  ```json
  "jamTooltip": "Sapphire Jam active: +1.3⚡ every 3m ({{minutes}}m remaining)"
  ```
- **Plurales canónicos**: Usar sufijos `_one` y `_other`.
  ```json
  "farmerCount_one": "{{count}} Farmer",
  "farmerCount_other": "{{count}} Farmers"
  ```

---

## 4. Números, Horas y Fechas con `Intl`
- Formatear siempre con las APIs nativas del navegador pasando `i18n.language`:
  ```javascript
  // Números / Monedas
  new Intl.NumberFormat(i18n.language).format(gold);

  // Horas y Fechas
  new Intl.DateTimeFormat(i18n.language, {
    hour: '2-digit', minute: '2-digit', second: '2-digit'
  }).format(lastSyncDate);
  ```

---

## 5. Estructura de Namespaces
Un archivo JSON por módulo para evitar colisiones entre PRs:
```
src/i18n/
  ├── index.js                     # Configuración central de i18next
  └── locales/
      ├── en/
      │   ├── common.json          # Textos compartidos, botones generales
      │   ├── header.json          # Barra superior HUD
      │   ├── tabs.json            # Títulos y accesos de pestañas
      │   └── errors.json          # ErrorBoundary y mensajes de excepción
      └── es/
          ├── common.json
          ├── header.json
          ├── tabs.json
          └── errors.json
```

---

## 6. Cómo Agregar un Nuevo Idioma (ej. Portugués `pt`)
1. Crear la carpeta `src/i18n/locales/pt/`.
2. Duplicar los archivos JSON de `en/` (`common.json`, `header.json`, `tabs.json`, `errors.json`).
3. Traducir los valores manteniendo intactas todas las claves.
4. Importar y registrar el nuevo idioma en `src/i18n/index.js` en `SUPPORTED_LANGUAGES` y `resources`.
5. Agregar el botón del nuevo idioma en `src/components/LanguageSwitcher.jsx`.
6. Ejecutar `npm test` para verificar que el test de paridad estricta pase al 100%.
